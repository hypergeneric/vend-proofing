# Vend

Vend is a self-hosted photography proofing and commerce application undergoing preservation-led modernization.

Start with the [documentation index](docs/README.md). Developers can use the [development guide](docs/DEVELOPMENT.md); photographers and site operators can use the [manual](docs/MANUAL.md).

For CSS/JavaScript source layout and build/watch commands, see [Front-end asset build](docs/DEVELOPMENT.md#front-end-asset-build).

The deployable web tree is `dist/`; configure the web server document root there. Source assets, tooling, and documentation remain above it. See [Repository and distribution layout](docs/DEVELOPMENT.md#repository-and-distribution-layout).
